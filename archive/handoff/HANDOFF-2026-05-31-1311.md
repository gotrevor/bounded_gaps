## 🧠 Context to carry forward
- **The key realization:** `EH`/`GEH`/`MPZ` were *contentless* `axiom _ : Prop`. So `GEH ϑ → EH ϑ` had
  no proof term — that's a **modeling gap, not deep math**. The fix is to give them real `def` bodies.
  This is also an *honesty upgrade*: a contentless `axiom EH : Prop` is satisfied by `True`, so
  `BombieriVinogradov : EH ϑ` asserted nothing; with a real body it asserts the actual theorem.
- **Trevor's design call (asked & answered this session): "Precise"** — model the discrepancy faithfully
  via von Mangoldt sums, not a lighter schematic Prop. Built in `Prerequisites.lean`: `window x`=`[x,2x]∩ℕ`,
  `coprimeRes q`, `discrepancy f x q a` = (residue-class sum) − (1/φ(q))(coprime-class sum),
  `maxDisc f x q : ℝ≥0` = `sup_a |Δ|` (ℝ≥0 so it's total + non-negative *for free* — that non-negativity
  is exactly what makes the sub-sum monotone), `IsSmooth δ x q` = Squarefree ∧ primeFactors ≤ x^δ.
  `EH ϑ`/`MPZ ϖ δ` = `∀A≥0,∃C>0,∀x≥2, ↑(∑_{q≤Q} maxDisc Λ x q) ≤ C·x/(log x)^A` (EH over `q≤x^ϑ`, MPZ
  over δ-smooth `q≤x^{1/2+2ϖ}`).
- **Why `eh_implies_mpz` fell easily:** MPZ's modulus set is EH's *filtered* to δ-smooth `q` at level
  `1/2+2ϖ`; the per-modulus term (`maxDisc Λ`) is identical. So it's a pure **sub-sum**
  (`Finset.sum_le_sum_of_subset` over ℝ≥0, cast back via `NNReal.coe_le_coe`). No analytic NT.
- **Why nothing downstream broke:** every consumer (Sieve `maynard_thm`, the `s2_*` axioms,
  Maynard/Polymath8b `*_under_EH/GEH`, Targets) threads the EH/GEH/MPZ hypothesis **opaquely** to a cited
  axiom — none unfolds its content. So real bodies are free for them. (Verified by grep + a full green build.)
- **Why `geh_implies_eh` is a real wall (don't be fooled into route (a) lightly):** GEH bounds Dirichlet
  *convolutions* `α⋆β`; EH bounds `Λ`. Faithfully, `GEH→EH` IS **Vaughan's identity** (decompose `Λ` into
  Type I/II pieces). mathlib has `Λ=μ⋆log` (`sum_moebius_mul_log_eq`) but **no Vaughan** — the bare `log`
  factor is too large; splitting it is precisely Vaughan. The `eh_implies_mpz` sub-sum trick does NOT
  transfer (there `Λ` is untouched; here it must be rebuilt). A "route (a)" semi-faithful shortcut
  (model GEH's class to swallow `Λ` via `Λ=μ⋆log` directly) exists but is ~60% and papers over BFI's
  technical conditions on the convolution factors — **an integrity compromise.** I deliberately did NOT
  start it. The honest path = build a Siegel-Walfisz def + faithful GEH convolution-discrepancy body +
  port Vaughan. Multi-session; only worth it if a Vaughan identity is on the horizon.

- `open Classical in` must go **immediately before the `def`** but *before its doc comment too* — placing
  it between the `/-- … -/` and the `def` is a parse error ("unexpected token 'open'; expected 'lemma'").
